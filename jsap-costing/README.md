# JSAP costing package (FSM NAP, PZ1019)

Prepared by Katrina Rae, Haskoning, 3 November 2026. Working material for team review.

**To use with Claude Code:** open this folder in Claude Code and say, for example:

- "Read CLAUDE.md, rebuild and verify the workbook, then build the dashboard."
- "Read CLAUDE.md. Add a new source for 2.5.1 and rebuild."
- "Read CLAUDE.md and docs/SKILL.md. Cost the Kosrae activities the same way."

**To review the costing without Claude Code:** open `workbook/JSAP_Costing_Workbook.xlsx` (tabs Chuuk, Worked examples, State factors, Cost basis, Source check, Change log), or review and edit `data/source_mapping.csv` in Excel.
